1.5.12
- report formatting overhaul: alphabetical order, per-show missing-episode totals, a summary
  line, and clear section separators, instead of a flat list of lines
- removed the debug dump tool (Settings > Debug) now that the "special" field is confirmed

1.5.11
- confirmed the real field: episodes have a "special" flag (0/1) from BetaSeries, independent of
  season number (a special can be numbered inside a regular season, e.g. Yellowstone S01E04)
- catch-up check now filters on that "special" field instead of assuming specials are season 0

1.5.10 - /episodes/list turned out to be the user's personal "to watch" queue (grouped by show,
  empty if nothing pending), not a show's full episode catalog - reverted debug tool to dump
  /shows/episodes raw data to find the actual "is special" field instead

1.5.9 - debug tool now tests /episodes/list (properly documented, has a "specials" param) instead of
  the undocumented /shows/episodes, to validate switching the whole catchup feature to it

1.5.8
- add a debug tool (Settings > Debug > "Dumper une saison") to inspect the raw BetaSeries episode
  JSON for a show/season, to find the field that marks an episode as "special" even when it's
  numbered within a regular season (not just season 0)

1.5.7
- fixed re-scraped episodes/movies (same Kodi library id reused) being silently skipped by the
  "recently added" dedup - now keyed by (id, dateadded) instead of just id, so a genuine re-add
  is processed again even if Kodi reused the same id
